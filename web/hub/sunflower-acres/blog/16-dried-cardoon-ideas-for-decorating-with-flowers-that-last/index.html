Which one is right for you

If you want one stem and no fuss — start with the single stem in a vase, or the bathroom stem. One flower, one spot, no water.

If you want a door or a wall — start with a wreath: the grapevine wreath for inside, the front-door wreath for outside. Or the shadow box, if you want it framed.

If you want a table — start with the fall centerpiece, the Thanksgiving table, the low tablescape, or the fairy lights centerpiece. All four are table ideas; pick the occasion.

If it's a wedding or a party — start with the wedding bouquet, and add the boutonniere for the same event.

If you want something small and handmade — start with the Christmas ornament. One head, one ornament.

If you want a bundle to keep or give — start with the pampas + lavender bundle or the holiday bundle. Both are bundles; the holiday one is the seasonal one.

If you want a look rather than a build — start with the mantel styling or the farmhouse vs boho vs modern comparison, and pick the style you like before you build anything.
